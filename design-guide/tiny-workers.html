01 · Brand

Tiny in stature, large in feeling.

Essence

Tiny Workers are pocket-sized AI beings. Each one is a specialist with a face, a voice, and remembered context. Hire one, build a studio of six, point them at real tools.

One sentence: Quiet, capable beings that get the work out.

Voice

  • Editorial, not corporate. Short sentences. Real verbs.
  • Warm, not cute. Confident, never loud.
  • Names over titles: Quinn drafted this, not The agent generated this.

Application rules

Rule 01 · The 60/30/10

60% Cream surface (#f5f1e9) or Jet white. 30% Midnight forest for type and dark blocks. 10% Awaking light for accents, focus rings, key CTAs and one hero moment per page.

Rule 02 · Never six at once

A composition uses no more than three palette colors as solids. The full spectrum only appears within atmospheric gradient artwork (aura orbs, hero washes).

Rule 03 · Awaking is a verb

Awaking light marks energy: a focus ring, an active dot, the primary CTA, the unread indicator. If everything is awake, nothing is — keep it < 10% of any frame.

Rule 04 · Pair, don't clash

Approved pairings: Midnight×Awaking (signature), Midnight×Golden, Sunset×Cream, Recovery×Cream. Avoid Golden×Awaking together (muddy) and Sunset×Recovery as solids (low contrast).

Contrast matrix (text on background)

WCAG 2.2 AA targets: 4.5 for body, 3.0 for large text (≥18.66px bold / ≥24px).

03 · Typography

A serif that breathes, a sans that ships.

Display & Editorial

Fraunces

Variable: opsz 9–144, wght 300–900, ital 0/1, SOFT 0–100.

Use for h1–h4, hero moments, names of beings. Set italic for emphasis — never bold-italic. Optical size 144 at display, 72 at h2, 32 below. Letter-space -2.5% at display, drop to -1% by h4.

UI & Body

Inter

Weights 300/400/500/600/700. Features: ss01, cv11.

Use for body, UI labels, buttons, navigation, in-product copy. Default body 16/26 at 400. Lead 18/28 at 400. Microcopy 13/20 at 400. Buttons 14/14 at 500.

Type scale

Modular 1.250. All display sizes use clamp() so they scale fluidly from 360px to 1440px.

Composition rules

Italic is for names & feeling.

Italicize being names (Quinn), key adjectives in headlines (tiny, quietly), and pull-quotes. Never italicize for general emphasis — use weight 600 in body instead.

One italic per headline, max.

A display with two italic phrases reads as decoration. One italic phrase reads as voice.

Measure: 60–75 characters.

Set max-width:62ch on body. Lead can run wider (72ch). Captions narrower (48ch).

06 · Motion

Always alive, never busy.

Three levels of motion: ambient (always on, breathing gradients), reactive (response to a user action, <240ms), and narrative (page reveals, hero entrances, 420–720ms). Reduced-motion users see only state-change fades.

Live motion specs (hover each card)

Bounce-in

700ms ease-emphasis · 4-stage. Use for chat-bubble arrival, toast appear.

Card flip

700ms ease-emphasis · use on identity switches (workers swapping).

Aura drift

1200ms × infinite alternate · ambient signature loop.

Shimmer pill

1100ms ease-standard · loading state, never CTAs.

Choreography

Stagger

Lists reveal with 60ms stagger per child. Max 8 staggered children — beyond that, fade the group as one.

child[i] delay = i * 60ms
total cap = 480ms
Hero entrance

Eyebrow → display headline (160ms after) → lead paragraph (260ms after) → CTAs (380ms after) → aura orb (fades in over 720ms in parallel).

Cursor presence

Buttons and beings tilt 4–6° toward the cursor on pointer-fine devices. Disable on touch. Disable on prefers-reduced-motion.

The ambient aura

The signature gradient breathes continuously: scale 1 → 1.015, hue-rotate 0 → -6°, over 9 seconds, ease-in-out, infinite alternate. Hue drift is the only place hue-rotate is permitted in the system.

@keyframes auraBreathe {
  0%   { filter: saturate(108%) hue-rotate(0);   transform: scale(1); }
  100% { filter: saturate(118%) hue-rotate(-6deg); transform: scale(1.015); }
}
.tw-aura { animation: auraBreathe 9s var(--ease-standard) infinite alternate; }

Link — three states

Inline links carry a 1px underline at all times. On hover, the underline thickens to 2px and the color shifts to Recovery green. Never use blue. Never strip the underline.

Card — hover choreography

  1. translateY(-4px) over 240ms, ease-emphasis
  2. Border lightens from --tw-line to --tw-line-strong
  3. Shadow steps from shadow-1 → shadow-3
  4. Inside a being card: aura scales to 1.12 and saturates, corner button fills Awaking and rotates -45°

Feedback patterns

Success

Toast with Recovery green left border, checkmark glyph, message in 14/22. 240ms slide+fade in, holds 4s, exits 200ms.

Warning

Inline below field. 13px Inter 500, color #8a6b1a (golden darkened). Glyph: ! in circle.

Error

Border #a85a5a, shake 240ms (translateX ±4px three times), message in 13px below field.

Cursor on canvas

On marketing surfaces, cursor becomes a 12px Awaking dot inside a 28px Midnight ring when over hoverable elements. Always falls back to native cursor when prefers-reduced-motion or pointer is coarse.

09 · Accessibility

Quiet, but never invisible.

Contrast

All body text meets WCAG 2.2 AA (4.5:1). All interactive elements 3:1 against adjacent. See contrast matrix in §02.

Focus

Every focusable element gets a visible 6px Awaking ring with 3px offset. Never remove :focus-visible. The ring uses non-color contrast (offset + size) too.

Motion

prefers-reduced-motion: reduce disables all transform animations, ambient gradients freeze, state changes degrade to 1ms opacity fades.

Type

Minimum body 16px, never less. Line-height ≥ 1.5 on body. Italic display text gets an aria-label fallback when typography becomes decorative.

Semantics

One h1 per page. Section headers in order. Being cards as <article>. Decorative auras carry aria-hidden="true"; identity auras carry role="img" with a meaningful label.

Targets

Touch targets ≥ 44×44px. Spacing between targets ≥ 8px. Pills meet this via height + padding.
